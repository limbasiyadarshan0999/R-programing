Academic success in tertiary education is driven by multiple quantitative predictors, including classroom lecture attendance, independent study hours, continuous internal assignment scores, and mid-term examination performance.

This empirical study analyzes a dataset of 50 student records. Through automated R preprocessing scripts, data integrity was verified with zero missing values (is.na()) and zero duplicate entries (duplicated()). 2. Introduction & Educational Analytics Domain

2.1 Educational Analytics Context

Educational Analytics (EA) and Learning Analytics (LA) have gained significant prominence in higher education. Colleges compile extensive historical records containing student demographics, continuous assessment marks, attendance logs, and examination results. Transforming raw academic data into actionable insights enables educators to identify learning bottlenecks, optimize teaching methodologies, and support at-risk students before final examinations.

2.2 Role of R Programming in Data Science

R is a world-class environment for statistical computing, data analysis, and graphics rendering. Developed by Ross Ihaka and Robert Gentleman, R provides an extensive ecosystem of built-in data structures (data frames, factors, matrices, vectors) and statistical commands (arithmetic means, standard deviation, interquartile ranges, linear models, correlation matrices) ideal for educational data evaluation.

2.3 Theoretical Framework & Literature Review

Educational psychology literature posits that academic outcomes depend on both behavioral effort (study time, lecture presence) and cognitive evaluation (assignments, mid-terms). In this model:

  • Independent Predictors: Attendance Percentage (\(X_1\)), Weekly Study Hours (\(X_2\)), Assignment Score (\(X_3\)), Internal Exam Score (\(X_4\)).
  • Dependent Response Variables: Final Exam Marks (\(Y_1\)), Overall Weighted Percentage (\(Y_2\)), Pass/Fail Result Status (\(Y_3\)).

set.seed(2026)
n_students <- 50
student_id <- sprintf("STU%03d", 1:n_students)

first_names <- c("Aarav", "Ananya", "Bhavya", "Chirag", "Darshan", "Devi", "Esha", 
                 "Gaurav", "Het", "Isha", "Jatin", "Kavya", "Karan", "Limbasiya", 
                 "Manav", "Neha", "Om", "Pooja", "Parth", "Riya", "Rohan", "Siddharth")
last_names  <- c("Patel", "Shah", "Joshi", "Mehta", "Trivedi", "Parmar", "Vora", "Desai")

student_names <- paste(sample(first_names, n_students, replace = TRUE),
                       sample(last_names, n_students, replace = TRUE))

gender <- sample(c("Male", "Female"), n_students, replace = TRUE, prob = c(0.52, 0.48))
attendance <- round(runif(n_students, min = 52, max = 98), 1)
study_hours <- round(4 + (attendance * 0.25) + rnorm(n_students, mean = 2, sd = 3), 1)
study_hours <- pmin(pmax(study_hours, 4), 35)

assignment_marks <- round(30 + (study_hours * 1.8) + (attendance * 0.3) + rnorm(n_students, mean = 0, sd = 5), 1)
internal_marks   <- round(25 + (study_hours * 1.6) + (attendance * 0.35) + rnorm(n_students, mean = 0, sd = 6), 1)
final_marks      <- round(20 + (study_hours * 1.9) + (attendance * 0.4) + rnorm(n_students, mean = 0, sd = 6.5), 1)

overall_marks <- round((assignment_marks * 0.20) + (internal_marks * 0.30) + (final_marks * 0.50), 1)
result <- ifelse(overall_marks >= 40 & attendance >= 60, "Pass", "Fail")
grade  <- ifelse(overall_marks >= 85, "A+", ifelse(overall_marks >= 75, "A", 
          ifelse(overall_marks >= 65, "B", ifelse(overall_marks >= 50, "C", 
          ifelse(overall_marks >= 40, "D", "F")))))

raw_student_data <- data.frame(Student_ID=student_id, Name=student_names, Gender=gender, 
                               Attendance=attendance, Study_Hours=study_hours, 
                               Assignment_Marks=assignment_marks, Internal_Marks=internal_marks, 
                               Final_Marks=final_marks, Overall_Marks=overall_marks, 
                               Result=result, Grade=grade, stringsAsFactors=FALSE)

write.csv(raw_student_data, file = "student_performance_data.csv", row.names = FALSE)
student_data <- read.csv("student_performance_data.csv", stringsAsFactors = FALSE)
